# Web 与应用项目分析

> 基于 [project-analysis-skill](https://github.com/Bamzzo/project-analysis-skill)（MIT）commit 0d594be（2026-05-28）改编，含内容修改与增补。

用于前端、后端、全栈、Electron、桌面 webview 或 API 服务类项目。

## 前端问题

- 使用了什么框架？
- 应用根在哪里？
- 路由如何处理？
- API client 定义在哪里？
- 全局状态存放在哪里？
- 认证如何处理？
- 环境变量如何加载？
- 有哪些 build/dev 脚本？
- 错误如何呈现给用户？

## 后端问题

- 使用了什么框架？
- 应用/服务在哪里创建？
- 路由在哪里注册？
- 安装了哪些中间件？
- 配置在哪里加载？
- 请求/响应 schema 定义在哪里？
- 业务逻辑在哪里？
- 调用了哪些外部服务？
- 错误如何返回？
- 日志如何写出？

## 全栈流程

追踪：

```text
用户交互
-> UI 处理器
-> API client
-> HTTP 请求
-> 后端路由
-> 服务/控制器
-> 数据库/外部 API
-> 响应
-> UI 状态更新
```

## 环境与运行时

识别：

- dev server 端口
- 后端端口
- 代理配置
- CORS
- 构建输出目录
- 适用时的 Electron main/preload/renderer 拆分
- 必需的本地服务
- 必需的环境变量

## 常见失败模式

- 前端指向了错误的后端 URL
- CORS 拦截请求
- 环境变量只在构建时可用
- 后端路由前缀不匹配
- API 响应结构发生变化
- 认证 token 缺失
- dev server 与打包应用行为不同
- 原生依赖与 Node/Electron 版本不兼容
- 生成的构建文件被误提交

## 验证

建议的检查：

- 类型检查
- 单元测试
- 构建
- 健康检查端点
- 手工 UI 冒烟测试
- 浏览器控制台日志
- Network 面板 / 请求日志
- 后端日志

## 建议的输出增补

对 Web/应用类项目，额外加入：

1. 前端运行时
2. 后端运行时
3. API 面
4. 环境变量
5. 前端到后端的流程
6. 构建与打包
7. UI 验证计划
